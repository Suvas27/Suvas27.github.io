HeartGuard: Hybrid Neural Network System on FPGA

Real-time cardiac fatigue and arrhythmia detection at the edge

The Problem

Wearable ECG monitoring needs real-time arrhythmia detection, but continuous deep-learning inference on FPGAs is power-hungry — while lightweight models alone aren’t accurate enough.

The Solution

  • Two-tier hybrid network: an always-on lightweight MLP monitors Heart Rate Variability (HRV) to flag fatigue
  • A 1D CNN activates only when fatigue is detected, classifying arrhythmias (AFib, PVC) from raw ECG
  • Both networks quantized to Q8.8 fixed-point and implemented as synthesizable Verilog RTL

EcoStreet: Automated Smart Street Lighting System

Adaptive, fault-aware lighting — patent application published

The Problem

Fixed-schedule street lights stay at full brightness all night regardless of need, wasting energy and delaying failure detection.

The Solution

  • LDR sensor detects ambient light to switch between off / dim / active modes
  • PIR motion sensor boosts brightness to 70% when pedestrians/vehicles are detected, dims to 60% otherwise
  • ACS712 current sensor continuously checks for open/short-circuit faults, flags them in real time

Neuromorphic Architecture — LIF Neuron Model

Computational foundation for brain-inspired spiking hardware

The Problem

Traditional neural networks are power-hungry; neuromorphic computing offers a brain-inspired, energy-efficient alternative — but needs a solid simulation foundation before hardware implementation.

The Solution

  • Simulated the Leaky Integrate-and-Fire (LIF) neuron model using Forward Euler numerical integration
  • Modeled membrane potential dynamics with threshold-based spike generation and reset
  • Swept input current to analyze firing-rate response, building a framework extensible to multi-neuron SNNs
GitHub Repo

Key Insights

  • Verified firing rate response matches theoretical LIF model
  • Extensible framework ready for hardware implementation
Python 3 · NumPy · Matplotlib · Jupyter Notebook
